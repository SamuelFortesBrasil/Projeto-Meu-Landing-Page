# Projeto Meu Landing Page
 Projeto de HTML, CSS e Javascript:
  Esse é meu Primeiro Projeto sendo desenvolvido sozinho, é simples, porém elegante.
 Um landing-page que foi contruido a partir da filosofia do Mobile Fist ,tendo compromisso em dar responsividade a múltiplos dispositivos.
 Além de ultilizar Javascript para interações dinâmicas e bacanas!
 Vale destacar que se teve o uso de tecnologias CSS recentes, grid layout e flex box, além da semântica do HTML.
